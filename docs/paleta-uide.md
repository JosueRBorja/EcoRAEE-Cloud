# Adaptación cromática de AWStore

Fuente: manual LINEAMIENTOS_MARCA_UIDE_24_EXTERNOS-1 (1).pdf, página 8, sección 07 Colores.

| Color del manual | Valor digital | Aplicación |
| --- | --- | --- |
| Pantone 221 C | #910048 | Acciones principales, selección, encabezados pequeños |
| Pantone 288 C | #002D72 | Navegación, cifras y zonas institucionales oscuras |
| Pantone 124 C | #EAAA00 | Indicador de navegación y acentos sobre azul |

Se usan blanco, superficies neutras y tintes derivados para campos, tarjetas y fondos. El dorado no se utiliza para texto pequeño sobre blanco. Éxito, error y advertencia conservan sus significados operativos. La marca AWStore, fotografías, distribución, tipografía y funcionalidades se conservan: esta entrega adapta colores, no añade ni modifica el logotipo institucional.

La hoja tema-uide.css se importa al final y centraliza la adaptación para todos los roles, catálogo, acceso y formularios. Se verificaron los contrastes de las combinaciones principales mediante luminancia relativa. La compilación frontend pasó. El acceso al servidor de desarrollo desde el navegador de revisión no estuvo disponible; queda pendiente la inspección visual interactiva en el navegador del usuario.
